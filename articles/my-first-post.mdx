After years of wrestling with [blogger.com](http://mossup.blogspot.com/) and getting frustrated with the clunky interface and how hard it is to add new content I eventually decided to put some effort into writing a new blog.

After working on a microservices platform recently, I was using a multitude of new technologies and in order to be able to switch context easily from ASP.NET to Docker to Ansible I started using [Typora](https://typora.io/) and markdown to write notes explaining the basic concepts of each technology as well as providing cheat sheets to remind me of common commands.

I  have experience of using JavaScript and I like working with React so the obvious choice was GatsbyJs. I worked through the basic [tutorial](https://www.gatsbyjs.com/docs/tutorial) which setup a simple blog site, and did some googling to get categories and code highlighting sorted. 

So far I have found GatsbyJs to be much better to work with than the blogger.com platform. I've actually enjoyed going through the tutorials and building a simple website. Being able to write the content in markdown makes it much easier to add new articles so far I'm pleased with the results.
